# Farmmantra Agro Chemicals

Laravel web administration and Flutter Android application for the Farmmantra franchise distribution network in Uganda.

- `Web/`: existing Laravel backend, responsive web interface and REST API.
- `app/`: existing Flutter application using the same backend.
- `docs/LOCAL_DEVELOPMENT.md`: local setup, demo accounts and Android connection instructions.
- `docs/IMPLEMENTATION.md`: requirement mapping, test evidence and remaining production work.

Local credentials, uploads, databases, dependency folders and generated builds are excluded from Git. Configure `.env` locally and use `--dart-define=API_BASE_URL=...` for the app.

The project is under active development. Review the implementation record before using real financial transactions.
